# HardOpsBoxcutterTutorial

This repository documents my progress through the HardOps/Boxcutter tutorial series by Blender Bros, focused on learning efficient hard-surface modeling workflows using Blender's HardOps and Boxcutter add-ons.

The goal of this project is to develop proficiency in Boolean-based modeling, streamline the creation of complex mechanical forms, and understand professional hard-surface modeling techniques for designing detailed sci-fi and mechanical assets.
